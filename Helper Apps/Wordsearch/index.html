    Standard Architecture

    Engine Specifications

    1

    4-Column Header Structure

    Every dataset must retain the canonical row: title,mini,midi,main. Sub-tier words are wrapped in double quotes as comma-separated values.

    2

    Grid Dimension Caps

    Mini: 8×8 grid → Maximum word length is 8.
    Midi: 10×10 grid → Maximum word length is 10.
    Main: 12×12 grid → Maximum word length is 12.

    3

    Character Sanitization

    Game runtime automatically removes whitespace, punctuation, and hyphens. For example, OLD-FASHIONED evaluates as OLDFASHIONED (12 characters).

    4

    Deterministic Board Fit

    The placement engine tests random coordinates over 120 iterations. Keeping word density between 5 and 8 words per tier guarantees 100% placement success.
