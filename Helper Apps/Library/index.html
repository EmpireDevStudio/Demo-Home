Archive Directory Rules & Workflow

1. Standard Directory Resolution

The archive controller resolves directories strictly structured under the root assets/ folder:

assets/
├── Financial/
│   ├── Q1_Statement.pdf
│   └── Projections_2026.xlsx
└── Guidelines/
    └── Brand_Manifesto.pdf

2. Clean Title Normalization

The controller strips underscores, hyphens, and file extensions. A file named Quarterly_Review-2026.pdf cleanly renders as Quarterly Review 2026 in the catalog view.

3. Deployment Pipeline

Click Export Assets → Archive Package (assets.zip), uncompress the package, and drop the resulting assets/ folder into your web project root.
